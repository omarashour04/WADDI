# WADDI Platform

This project uses a feature-first, layered architecture for scalability and maintainability.

- Main entry: `lib/main.dart`
- Root widget and app setup: `lib/app.dart`
- Features: `lib/features/`
- Core utilities/services: `lib/core/`
- Shared widgets/themes: `lib/shared/`
- Routing: `lib/routes/`
- Generated files: `lib/generated/`
- Static assets: `assets/`
- Tests: `test/`, `integration_test/`

See `lib/` for the main application logic.
